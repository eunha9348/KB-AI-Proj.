# 청년·대학생 주택 안전진단 & 맞춤형 금융연계 플랫폼 (은행 AI 공모전 프로토타입)

부동산 정보가 부족한 2030세대의 **전세 사기·깡통전세 리스크를 AI로 사전 차단**하고,
위험도(0~100%)에 따라 **은행 금융상품(보증보험 / 차등금리 대출)을 자동 큐레이션**하는
세입자 친화적 부동산 금융 플랫폼의 동작 프로토타입입니다.

> **컴플라이언스 원칙** — 네이버/직방 등 무단 크롤링을 **일절 사용하지 않습니다.**
> 서울시 열린데이터광장(실거래가)·국토부 건축물대장·인터넷등기소(제휴) 등
> **공공데이터 및 정식 제휴 데이터**만으로 구성되어 은행 내부 시스템 편입이 가능합니다.

---

## 🖼️ 프로토타입 미리보기

- **바로 실행(설치 불필요):** [`frontend/standalone.html`](frontend/standalone.html) 파일을 브라우저로 열기만 하면 됩니다. (데이터 내장, 인터넷 불필요)
- 지도 배경 위에 매물을 **위험등급 색상(안전·주의·경고·위험)** 과 **원 크기(시세)** 로 표시하고,
  매물 클릭 시 **위험도 게이지 + 전세가율/선순위채권비율 + 추천 금융상품** 을 보여줍니다.
- 하단에 **위험등급 분포(도넛)**, **자치구별 평균 위험도(막대)**, **전세가율×위험도(산포)** 도표 제공.

## 🚀 실행 방법

### 0) 요구사항
- Python 3.9+ (표준 라이브러리만으로 동작). Flask는 선택.

### 1) DB 생성 (ETL)
```bash
python data/etl.py
# → db/housing.db 생성, 자치구 25개 · 매물 300건 · 위험도 진단 적재 (FALLBACK 평균시세)

# 실제 서울시 공공데이터 사용 시 (서울 열린데이터광장에서 인증키 발급 후):
SEOUL_API_KEY=발급키 python data/etl.py
# → 매매(tbLnOpendataRtms) + 전월세(tbLnOpendataRentV) 실거래가를 실제로 호출해
#   자치구별 평균 매매가·전세가를 실데이터로 갱신하고, 원본 거래를 transactions 테이블에 적재.
#   API 키가 없거나 호출이 실패하면 자동으로 FALLBACK 평균시세를 사용합니다(서비스 중단 없음).
```

> **필드 매핑 안내:** `data/seoul_api.py` 의 `FIELD_CANDIDATES` 는 서울 열린데이터광장의
> 통상적인 컬럼 명명 규칙(예: `SGG_CD`, `GRFE`, `THING_AMT` 등)을 후보로 등록해 두었습니다.
> 실제 발급받은 키로 처음 호출했을 때 컬럼이 매칭되지 않으면, 에러 메시지에 표시되는
> 실제 응답 키를 `FIELD_CANDIDATES` 에 추가하면 됩니다. (임의의 값을 지어내지 않고,
> 매칭 실패 시 안전하게 FALLBACK으로 전환하도록 설계했습니다.)

### 2A) 라이브 버전 (백엔드 + 실지도)
```bash
python backend/app.py        # http://localhost:8000
```
브라우저에서 `http://localhost:8000` 접속 → Leaflet 실지도 + 실시간 API.

### 2B) 배포 버전 (파일 하나)
```bash
python data/export_json.py       # DB → frontend/data.json
python data/build_standalone.py  # → frontend/standalone.html
```
`frontend/standalone.html` 을 브라우저로 열면 끝. (서버·인터넷 불필요)

## 🧮 위험도 산출 로직 (`data/risk_engine.py`)

```
전세가율          = 보증금 / 추정매매가
선순위채권비율     = (근저당설정액 + 보증금) / 추정매매가   ← 1.0 초과 시 '깡통전세' 신호
```

| 구간 | 산정 |
|------|------|
| 선순위채권비율 ≤ 0.5 | 0점 (매우 안전) |
| 0.5 ~ 1.0 | 선형 0→70점 |
| 1.0 초과 | 70→100점 (1.3배 이상 100) |
| 전세가율 0.8 초과 | 최대 +15점 가산 |
| 위반건축물 | +12점 가산 |

**등급:** 안전(0~29) · 주의(30~54) · 경고(55~79) · 위험(80~100)

## 🏦 KB국민은행 실제 금융상품 매칭 (`data/kb_products.py`)

추천 상품은 위험등급 단일 기준이 아니라 **위험등급 + 보증금 규모**를 함께 보는
다요소 매칭 알고리즘(`match_product()`)으로 결정됩니다. 모든 상품은 KB국민은행
공식 상품안내(kbthink.com 등)에 실제로 존재하는 상품입니다. 참고 링크(`reference_url`)는
로그인 세션이 있어야 렌더링되는 내부뱅킹 딥링크 대신, 세션 없이도 항상 열리는 기관 공식
도메인(kbthink.com / nhuf.molit.go.kr / khug.or.kr)만 사용합니다.

```
위험등급 '위험'  → 대출 매칭 보류, HUG 전세보증금반환보증 가입 필수 안내
위험등급 '경고'  → KB스타 전세자금대출 (HUG 전세금안심대출보증) 매칭
위험등급 '안전'/'주의'
   ├─ 보증금 ≤ 3억원(정책자금 한도)  → 청년전용 버팀목 전세자금대출 (정부 최저금리) 우선 매칭
   └─ 보증금 > 3억원                 → KB 청년 맞춤형 전세자금대출 매칭
        └─ 등급이 '안전'이면 이 플랫폼이 제안하는 안전매물 특별우대 −0.3%p 추가 적용
           (KB 공시금리가 아닌, 본 제안이 신설을 제안하는 차등금리 정책)
```

| 상품 | 취급기관 | 금리(참고값) | 최대한도 | 매칭 등급 |
|------|---------|------|------|-----------|
| **청년전용 버팀목 전세자금대출** | 주택도시기금(KB국민은행 등 수탁) | 연 2.00~3.10% | 2억원 (보증금 3억원 이하) | 안전·주의 |
| **KB 청년 맞춤형 전세자금대출** | KB국민은행 | 신규COFIX+가산금리(변동) | 2억원 | 안전·주의(정책자금 한도 초과) |
| **KB스타 전세자금대출(HUG 전세금안심대출보증)** | KB국민은행 | 연 3.94~5.34%(2025-05 공시) | 2.22억원 | 경고 |
| **전세보증금반환보증 가입 필수 안내** | 주택도시보증공사(HUG) | 해당없음(보증보험) | - | 위험 |

> ⚠️ 위 금리·한도는 KB국민은행 공식 페이지에 공개된 정보를 인용한 **참고값**이며,
> 실제 적용 조건은 신용도·COFIX 변동·정책 개정에 따라 달라집니다. 실서비스 전환 시
> KB국민은행 API 또는 영업점 확인으로 대체해야 합니다. 존재하지 않는 상품이나
> 임의의 수치는 사용하지 않았으며, 확정할 수 없는 항목(KB 청년 맞춤형 전세자금대출의
> COFIX 연동 변동금리 등)은 수치 대신 설명 텍스트로 남겨 두었습니다.

## ⚠️ 데이터 관련 고지
`SEOUL_API_KEY` 없이 실행하면 매물 데이터는 자치구 평균 시세를 기반으로 생성한
**시연용 샘플**입니다. `SEOUL_API_KEY` 를 설정하면 자치구별 평균 매매가·전세가는
서울 열린데이터광장의 **실제 실거래가**로 갱신됩니다. 다만 개별 매물의 정확한 주소·
근저당 설정액·위반건축물 여부는 등기부·건축물대장·공인중개사 제휴(기획서의 Plan B)가
아직 연동되지 않아 통계적으로 생성됩니다 — 이는 원 기획서의 설계(개별 호가가 아닌
"해당 지역의 평균 매매가와 전월세가 비교"로 전세가율을 산출)와 일치합니다.
KB국민은행 상품명·금리·한도는 실제 공개 자료 기준이며, 존재하지 않는 상품을 지어내지
않았습니다.

자세한 사용법은 [`docs/USAGE.md`](docs/USAGE.md) 및 Notion 문서를 참고하세요.
