# 청년·대학생 주택 안전진단 & 맞춤형 금융연계 플랫폼 (은행 AI 공모전 프로토타입)

부동산 정보가 부족한 2030세대의 **전세 사기·깡통전세 리스크를 AI로 사전 차단**하고,
위험도(0~100%)에 따라 **은행 금융상품(보증보험 / 차등금리 대출)을 자동 큐레이션**하는
세입자 친화적 부동산 금융 플랫폼의 동작 프로토타입입니다.

> **컴플라이언스 원칙** — 네이버/직방 등 무단 크롤링을 **일절 사용하지 않습니다.**
> 서울시 열린데이터광장(실거래가)·국토부 건축물대장·인터넷등기소(제휴) 등
> **공공데이터 및 정식 제휴 데이터**만으로 구성되어 은행 내부 시스템 편입이 가능합니다.

## 🖼️ 프로토타입 미리보기

- **바로 실행(설치 불필요):** [`frontend/standalone.html`](frontend/standalone.html) 파일을 브라우저로 열기만 하면 됩니다. (데이터 내장, 인터넷 불필요)
- 상단에 **데이터 출처 상태바**(지표별 실API/FALLBACK, 뉴스 실기사 건수)로 신뢰성을 투명 공개.
- 지도 위에 매물을 **위험등급 색상**과 **원 크기(시세)** 로 표시하고, 매물 클릭 시 **위험도 분해
  (펀더멘털 vs 컨텍스트) + 금융지표 + 뉴스 리스크 근거(실제 기사 링크) + 맞춤 KB 상품** 을 보여줍니다.
- 하단에 **위험등급 분포(도넛)**, **자치구별 평균 위험도(막대, 피해다발구 표시)**,
  **뉴스 리스크 브리핑(2-gram 위험어)** 도표 제공. 라이트/다크 테마 모두 지원.

```bash
python data/etl.py

# 실제 서울시 공공데이터 사용 시 (서울 열린데이터광장에서 인증키 발급 후):
SEOUL_API_KEY=발급키 python data/etl.py
# → 매매(tbLnOpendataRtms) + 전월세(tbLnOpendataRentV) 실거래가를 실제로 호출해
#   자치구별 평균 매매가·전세가를 실데이터로 갱신하고, 원본 거래를 transactions 테이블에 적재.
#   API 키가 없거나 호출이 실패하면 자동으로 FALLBACK 평균시세를 사용합니다(서비스 중단 없음).
```

**매번 커맨드에 키를 붙이기 귀찮다면 `.env` 파일 사용:**
```bash
cp .env.example .env      # 템플릿 복사
vi .env                   # SEOUL_API_KEY=발급키 로 채워넣기
python data/etl.py        # 이후로는 키 없이 그냥 실행해도 .env를 자동으로 읽는다
```
`.env`는 `.gitignore`에 등록되어 있어 **GitHub에는 절대 올라가지 않는다.** 저장소에 커밋되는
파일은 값이 비어있는 템플릿(`.env.example`)뿐이며, 실제 키는 로컬 `.env`에만 존재한다.

> **필드 매핑 안내:** `data/seoul_api.py` 의 `FIELD_CANDIDATES` 는 서울 열린데이터광장의

## 🧮 위험도 산출 로직 (`data/risk_engine.py`)

기존 금융지표에 **뉴스 감성분석(2-gram)** 을 결합한 2단 구조입니다.

```
최종 위험도 = 100 × ( 0.78 · f  +  0.22 · c )

 f (펀더멘털, 물건 고유 위험, 0~1)          c (컨텍스트, 지역 환경 위험, 0~1)
 ├─ 선순위채권비율 = (근저당+보증금)/매매가   ├─ 전세가 변동성(CV, 실거래가 기반)
 │   (지배적, 1.0 초과 시 '깡통전세')        └─ 뉴스 감성 '초과분'(2-gram × 실제 기사)
 ├─ 전세가율 = 보증금/매매가
 ├─ 위반건축물 · 주거유형(비아파트 가산) · 노후도
```

- **펀더멘털 f 가 지배(78%)**, 감성은 조절 요소(뒤집기 방지). 감성은 서울 기준선을 **초과하는
  만큼만** 반영해 전세사기 피해다발 자치구(관악·강서 등)만 차등 가산합니다.
- **뉴스 감성**은 `data/news_sentiment.py` 가 2-gram 위험 렉시콘(전세사기·깡통전세·보증사고 등)을
  **실제 언론기사 코퍼스**(URL 기록, 허구 아님)에 매칭해 산출합니다.
- **방법론 유효성**은 `python data/validate_risk.py` 로 재현·검증됩니다 →
  [검증 리포트](docs/risk_methodology_validation.md) (단조성 OK, 시나리오 4/4, 선순위 Spearman ρ≈0.97,
  펀더멘털 98% 지배, 감성 제거 시 등급변동 7%).

**등급:** 안전(0~29) · 주의(30~54) · 경고(55~79) · 위험(80~100)

## 🏦 KB국민은행 실제 금융상품 매칭 (`data/kb_products.py`)

추천 상품은 위험등급 단일 기준이 아니라 **위험등급 + 보증금 규모**를 함께 보는
다요소 매칭 알고리즘(`match_product()`)으로 결정됩니다. 모든 상품은 KB국민은행
공식 상품안내(kbthink.com 등)에 실제로 존재하는 상품입니다. 참고 링크(`reference_url`)는
로그인 세션이 있어야 렌더링되는 내부뱅킹 딥링크 대신, 세션 없이도 항상 열리는 기관 공식
도메인(kbthink.com / nhuf.molit.go.kr / khug.or.kr)만 사용합니다.

```
보증금 > 4.44억(HUG·HF 한도 초과)  → KB스타 전세자금대출(SGI 서울보증, 최대 5억) 매칭
위험등급 '위험'  → 대출 매칭 보류, HUG 전세보증금반환보증 가입 필수 안내
위험등급 '경고'  → 선순위채권비율 ≥90% : KB스타 전세자금대출(HUG 반환보증 결합)
                 선순위채권비율 <90% : KB스타 전세자금대출(HF, 보증료 저렴)
위험등급 '안전'/'주의'
   ├─ 보증금 ≤ 3억원(정책자금 한도)  → 청년전용 버팀목 전세자금대출(정부 최저금리) 우선
   └─ 보증금 > 3억원                 → KB 청년 맞춤형 전세자금대출
        └─ 등급이 '안전'이면 안전매물 특별우대 −0.3%p 추가(본 제안의 신설 차등금리 정책)
```

| 상품 | 보증기관 | 금리(참고값) | 최대한도 | 매칭 조건 |
|------|---------|------|------|-----------|
| **청년전용 버팀목 전세자금대출** | 주택도시기금(HUG 협약) | 연 2.00~3.10% | 2억원 | 안전·주의 + 보증금≤3억 |
| **KB 청년 맞춤형 전세자금대출** | 한국주택금융공사(HF) | 신규COFIX+가산금리(변동) | 2억원 | 안전·주의 + 정책한도 초과 |
| **KB스타 전세자금대출(HF)** | 한국주택금융공사(HF) | 연 3.70%~(2024) | 2.22억원(채권보전 4.44억) | 경고 + 선순위<90% |
| **KB스타 전세자금대출(HUG)** | 주택도시보증공사(HUG) | 연 3.94~5.34%(2025-05) | 2.22억원(채권보전 4.44억) | 경고 + 선순위≥90% |
| **KB스타 전세자금대출(SGI)** | 서울보증보험(SGI) | 연 3.70%~(2025-05) | 최대 5억원 | 보증금>4.44억(고액) |
| **전세보증금반환보증 가입 필수 안내** | 주택도시보증공사(HUG) | 해당없음(보증보험) | - | 위험 |

> ⚠️ 위 금리·한도는 KB국민은행 공식 페이지에 공개된 정보를 인용한 **참고값**이며,
> 실제 적용 조건은 신용도·COFIX 변동·정책 개정에 따라 달라집니다. 실서비스 전환 시
> KB국민은행 API 또는 영업점 확인으로 대체해야 합니다. 존재하지 않는 상품이나
> 임의의 수치는 사용하지 않았으며, 확정할 수 없는 항목(KB 청년 맞춤형 전세자금대출의
> COFIX 연동 변동금리 등)은 수치 대신 설명 텍스트로 남겨 두었습니다.

## ⚠️ 데이터 관련 고지 (허구 금지 원칙)
- **매물 개별 수치는 시연용 샘플**: 매매가·보증금·근저당은 자치구 평균 기반 통계적 생성값입니다
  (등기부·건축물대장·공인중개사 제휴 전). 이는 원 기획서 설계("지역 평균 매매가·전월세가 비교"로
  전세가율 산출)와 일치합니다. `SEOUL_API_KEY` 설정 시 자치구 평균 시세·전세가 변동성은 서울
  열린데이터광장 **실제 실거래가**로 갱신됩니다(지표별 실API/FALLBACK 출처를 UI·DB에 정직 표기).
- **뉴스 감성은 실제 기사 기반**: `data/news_sentiment.json` 의 코퍼스는 모두 실재하는 언론 보도이며
  URL·출처·날짜를 기록합니다(UI 인스펙터에서 클릭 검증 가능). 자치구별 감성은 해당 자치구를 실명
  보도한 근거가 있을 때만 차등하고, 근거 없는 자치구는 서울 기준선을 상속합니다 — **존재하지 않는
  자치구 수치를 지어내지 않습니다.** 코퍼스는 위험 주제를 겨냥해 수집돼 선택편향이 있으므로,
  감성 기준선을 ≈0.5로 보정해 금융 펀더멘털을 압도하지 않게 했습니다(검증 리포트 참조).
- **KB 상품명·금리·한도는 실제 공개 자료 기준**이며, 존재하지 않는 상품·임의 수치를 지어내지
  않았습니다. 확정 불가 항목(COFIX 연동 변동금리 등)은 수치 대신 설명 텍스트로 남겼습니다.

  주장하지 않습니다. 대신 매물의 **실제 좌표·지역**을 카카오맵 로드뷰(실제 거리 사진)·지도·
  네이버 지도·국토부 실거래가 공개시스템으로 열어, 해당 위치에 실제 부동산·거래가 존재함을
  사용자가 직접 검증하게 합니다(무단 크롤링·가짜 사진 삽입 없음).
